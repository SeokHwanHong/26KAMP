2. 최종 아이디어 (Claude 확정본)
======================================================================
[데이터 유형 분기 — 근거를 숫자로]
- 개발 데이터 4-fold OOF에서 순위가 무작위보다 나은지 순열 검정(Test 미사용).
- CN7: AUC 0.870, p 0.001 → 입력에 신호 있음 → 모델 판정
- RG3: AUC 0.451, p 0.776 → 신호 없음 → 분포 감시

[CN7 — 랜덤 포레스트 + 검사 예산]
- 근거(개발 OOF, 위험 11개, 상위 10% 검사): RF 9개(AUC 0.940) > LR 8개(0.882) > OCSVM 4개(0.798)
- 배치마다 RF 점수 상위 10% 제품을 검사 대상으로 표시(inspection_priority.*).
- 모델 교체는 "같은 검사량에서 위험을 더 많이 찾는가"로 판단. 고정 임계값 기준은 쓰지 않음.
- 선정에 쓴 평가 자료로는 승격 불가(선정용·승격용 자료 분리).

[RG3 — 드리프트 기반 불확실 구간]
- 제품별 불확실 단계: 높음(지속 변화·학습 범위 밖) / 중간(1회 변화·정보 부족) / 낮음.
- 배치별 불확실 구간: 분포가 가장 많이 바뀐 변수·조합 상위 8개.
- 과거 위험 이력 구간은 참고 표시만(예측력 미검증).
- "불량 위험도"가 아니라 "판단 불확실 정도"로 설명한다.

[공통 안전장치]
- 같은 배치 재전송·제품 ID 중복 차단(같은 로트가 두 번 집계되어 재학습이 열리는 문제 방지).
- Test는 모델·임계값 선택에 쓰지 않음. 비라벨은 감시·추론에만 사용.

| 노트북 LR 코드 복사본 | .py와 어긋나도 모름 | 동기화 테스트 추가(다르면 실패) |
