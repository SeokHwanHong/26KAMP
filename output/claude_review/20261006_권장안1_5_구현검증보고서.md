## 검증 범위

`test_governance_runtime.py`의 관련 11개 검사를 실행했다. 격리 상태의 합성 입력이며 현장 성능을 입증하지 않는다.

- 검사 비율/담당자가 없으면 실제 계획과 승인 작업 보류.
- RG3 우선·무작위 대상 중복 없음, 전체 예산 일치, 재현 가능한 seed.
- 라벨을 바꿔도 선정 대상에 정답 누수 없음. 너무 작은 예산은 보류.
- 생산 시간대·원천 ID 필수, 실제 기간 선택과 위험 이력 보존.
- 누적 CT 승인 필요 및 부모 설정 유지.
- 정책 변경 후 승인 재사용 차단.
- 승인 참조 갱신·보존·롤백, 위험 패턴의 새 정상 편입 차단.
- CN7 독립 제품 성과와 승인 gate, 모델·역할 롤백.
- RF→LR 승인 전환이 실제 검사 순위 모델과 기준선 정책에도 반영됨.

제품 검사 성과 테스트의 초기 모델은 의도적으로 약하게 만든 합성 비교 모델이다. 실제 CN7 운영 RF보다 LR가 우수하다고 주장하는 실험이 아니다.

## 현장 값이 필요한 항목

정책 방향 1~5는 확정했다. 아래는 운영 설정값이다.

1. RG3 waiting/normal/watch/review 전체 검사 비율과 그중 무작위 비중.
2. ct/promote/reference/rollback 실제 승인 담당자.
3. recent를 사용할 경우 실제 생산 기간·공정 버전·학습 패턴 상한.

사용자에게 비율과 담당자 설정 질문을 보냈으며, 답변이 없는 값은 임의로 만들지 않는다.
`GOVERNANCE_SETTINGS.template.json`은 빈 담당자·미설정 샘플링·누적 학습으로 둔다. 실제 runtime에 설치하지 않았다.
미설정 시 보류되는 것은 의도된 동작이다. 실제 생산 시각이 없는 대회 자료에 recent 시간순 학습을 적용하지 않는다.
