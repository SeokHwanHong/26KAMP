# KAMP 운영 정책 확정 사항 (권장안 1~5)

현행화 기준: develop_seo `9c953ee`, 2026-10-06 PDF 검토 대응.
2026-10-06 사용자 전달: 팀장 검토결과 1~5번 권장안을 모두 채택했다.
아래 권장 방향은 확정 정책이며 governance_runtime과 GOVERNANCE_OPERATIONS.md에 연결했다.
RG3 단계별 검사 비율, 실제 승인 담당자, recent 사용 시 실제 기간·공정 버전·상한은 운영 필수 설정값으로 남긴다.
정책 방향의 미결정 항목이 아니라 현장 값을 입력해야 하는 상태다. 실제 runtime에는 임의 값을 설치하지 않는다.

## 1. CN7의 검사 모델 역할

**현재:** RF를 초기 운영 기준으로 사용하고, LR/RF/OCSVM 비교·선정은 별도 후보 근거다. 선정만으로 실제 검사 모델 종류가 바뀌지는 않는다.

**결정:** RF를 기준으로 유지할지, 독립 평가 결과에 따라 모델 종류도 교체할지.

**권장:** 당분간 RF 기준을 유지하고 모델 교체는 독립 제품 검사 성과가 확인된 경우 명시적으로 승인한다. 최적 모델 자동 전환을 지금 추가하지 않는다.

**반영:** 독립 제품 성과·승인 통과 후 모델 종류·버전·검사 비율·tie 규칙을 inspection_role로 묶어 전환·롤백한다. 일반 후보 선정만으로 전환하지 않는다.

## 2. RG3 경보 뒤의 실제 검사량

**현재:** review이면 배치 전체에 높은 판단 불확실성을 표시한다. 이 표시는 불량 확률 또는 전수검사 계약이 아니다.

**결정:** 관찰·주의·검토 단계마다 검사할 제품 수/비율, 선택 방식과 담당자를 정해야 한다.

**권장:** 범위 밖·정보 부족·변화 구간의 우선검사와 무작위 표본검사를 함께 사용한다. 정확한 비율은 현장 검사 비용과 처리 여력에 맞춰 사전에 합의한다. 결과를 보고 비율을 사후 조정하여 성능을 주장하지 않는다.

**반영:** 우선검사+무작위 검사 계획은 구현했다. 현장 비율이 없으면 held_configuration으로 보류하며 공정 조건 추천은 제공하지 않는다.

## 3. 초기 입력 기준선을 언제 갱신할지

**현재:** 모델 교체 후에도 입력 참조 및 RG3 구간 라벨 참조는 초기 개발 자료를 유지한다. 새 모델 출력 구간만 다시 계산한다.

**결정:** 계속 초기 공정과 비교할지, 승인된 공정 변경 후 새 참조를 만들지.

**권장:** 초기 기준은 보존하고, 실제 검사로 정상 공정이 확인된 경우에만 승인된 참조 버전을 추가한다. 모델 교체와 참조 교체는 분리하여 각각 근거와 롤백을 기록한다.

**실행 조건:** 생산 시간·입력 좌표·검사 라벨 확보, 참조 표본 조건, 승인자, 이전/새 기준 병행 비교 기록. update-reference/rollback-reference로 명시적 전환하며 변화 배치를 자동 흡수하지 않는다.

## 4. 과거 위험 이력과 최근 학습 대상

**현재:** 과거 corpus와 새 배치를 합쳐 패턴별 최대 라벨을 유지한다. 새로운 정상 라벨로 과거 위험 이력을 삭제하지 않는다.

**결정:** 학습도 계속 전체 누적할지, 최근 기간/공정 버전 중심으로 구성할지.

**권장:** 감사용 위험 이력은 영구 보존한다. 최근 적응이 필요하면 학습 대상만 별도의 기간·공정 버전 정책으로 선택한다. 실제 생산 시간 없이 행 번호를 기간으로 사용하지 않는다.

**반영:** cumulative 기본과 실제 생산 시각·공정 버전 기반 recent 선택을 구현했다. 학습 표본·상한·평가 중복 조건을 확인하고 과거 위험은 최대 라벨로 유지한다.

## 5. CT와 승격의 승인 근거·책임

**현재:** review, 원인 문자열, 라벨 배치, 고유 표본 조건과 명시적 명령이 필요하다.

**결정:** 누가 원인·정상 공정·학습 모델·배치·평가 독립성을 확인하고 승인할지.

**권장:** 바뀐 표현/변수, 입력·센서 오류 여부, 정상 공정 검사 근거, 영향을 받는 모델, 라벨 출처, 학습·평가 분리, 검사 예산과 승인자를 하나의 검토 기록에 연결한다. review 자체를 자동 재학습 명령으로 취급하지 않는다.

## 이번 코드 보완에서 택한 안전한 기본값

- 실제 운영 모델·기준선·기존 LR 결과는 변경하지 않는다.
- 구형 평가 이관은 과거 기록을 보존하고 후속 평가 사본만 만든다. 독립 승격용 자격을 소급 부여하지 않는다.
- 근거가 손상된 구형 자료는 원천 복구 전까지 거부한다.
- 정책/기준선이 바뀌었다가 복귀해도 연속 경보 횟수는 새로 시작한다.
- RG3 기준선 포인터 준비/복구는 별도 운영 작업이다. 실제 운영 상태를 자동 초기화하지 않는다.

이 결정들은 정상 분류 정확도를 보장하는 설정이 아니다. 현장 제품 단위 성과·비용과 책임 범위를 정하는 운영 계약이다.
