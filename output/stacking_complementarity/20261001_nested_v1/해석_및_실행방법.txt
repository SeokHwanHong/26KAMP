KAMP 2차 모델 결합 실험

결론
CN7에서는 개발 검증에서 보완 효과가 있었지만 후속 테스트에서 랜덤포레스트
단독보다 더 많은 위험 패턴을 찾지는 못했다. RG3에서는 개발 검증의 개선이
후속 테스트로 이어지지 않았다. 두 데이터에 공통으로 유효한 개선은 입증되지 않았다.

방법
1차: 원변수 랜덤포레스트 위험 점수, 정상 관계식 Ridge 잔차 상위3 평균,
     정상 패턴으로 학습한 Isolation Forest 이상 점수.
2차: 세 점수를 표준화한 뒤 C=0.1 로지스틱 회귀로 실제 라벨을 학습.
비교: 1차 각 모델, 세 점수의 백분위 단순 평균, 학습한 2차 결합 모델.
이전 실험과 달리 이번 관계 잔차 점수는 학습 구간의 정상 패턴 전체로 관계식을
적합했다. 원변수 RF 설정은 이전 기준선과 같다. 비라벨 데이터는 사용하지 않았다.
기존 패턴 기준 4개 외부 fold를 그대로 사용했다. 각 외부 학습 구간 내부에서
3-fold OOF 예측을 만들어 2차 모델을 학습했다. 바깥 검증 자료는 내부 모델
학습이나 점수 표준화에 들어가지 않았다. 최종 모델은 개발 데이터만으로 재학습했다.
원래 패턴 단위 최대 라벨을 사용하므로 동일 입력에서 불량 이력이 있으면 위험이다.
행별 불량 판정이나 실제 시간순 검증 실험이 아니다.

주 지표: 전체의 상위 10%를 검사할 때 찾는 위험 패턴 수
CN7 개발: 484개 중 49개 검사 / 위험 11개
  RF 10개, 관계잔차 6개, IF 7개, 단순결합 7개, 2차결합 11개 탐지.
CN7 테스트: 122개 중 13개 검사 / 위험 3개
  RF 3개, 관계잔차 1개, IF 1개, 단순결합 1개, 2차결합 3개 탐지.
RG3 개발: 472개 중 48개 검사 / 위험 20개
  RF 2개, 관계잔차 0개, IF 1개, 단순결합 0개, 2차결합 4개 탐지.
RG3 테스트: 119개 중 12개 검사 / 위험 5개
  RF 0개, 관계잔차 1개, IF 0개, 단순결합 1개, 2차결합 0개 탐지.
검사 수는 10%를 올림했다. 개발 OOF 점수 전체에서 상위 비율을 계산한 값이며,
개별 배치마다 비율을 적용한 운영 성능과 같다고 가정하지 않는다.
동점은 무작위 선택 시 기대 탐지 수와 최소/최대를 저장했다.

고정 임계값에 대한 주의
개발 OOF F1로 고른 임계값을 적용하면 CN7 결합 모델은 테스트 TP=1 FP=0 FN=2,
F1=0.5이다. RF의 F1=0.353보다 높지만 RF는 TP=3 FP=11 FN=0이다.
따라서 결합 모델이 불량을 더 많이 잡았다는 해석은 틀리다.
상위 10% 검사 정책과 고정 임계값 정책은 다른 판단 방식이다.
RG3 결합 모델의 고정 임계값 결과는 TP=0 FP=13 FN=5, F1=0이다.

권고
CN7 결합은 검사 우선순위 후보로 남길 수 있지만 우월성은 미확인이다.
RG3에는 결합 모델을 적용할 근거가 부족하다. 복잡도를 추가하기 전에 라벨과
공정 기록의 대응, 동일 입력 반복의 의미를 점검할 필요가 있다.
이번 테스트는 이미 관찰한 데이터이고 위험 수가 3/5개뿐이다. 모델별 점수
분포 이동과 작은 표본 때문에 개발 성능이 재현되지 않을 수 있다.
새로운 독립 라벨 데이터 없이는 개선이나 배포 신뢰도를 확정하지 않는다.

실행 (패키지/프로젝트 루트)
python modeling/stacking_complementarity_experiment.py
python tmp/verify_stacking_experiment.py
이미 결과 폴더가 있으면 덮어쓰지 않고 중단한다. 재실행하려면 코드의 OUT을
새 폴더로 변경한다. 의존성은 modeling/relationship_requirements.txt에 있다.
검증 스크립트는 저장 예측으로 지표를 다시 계산하고 내부·외부 행 분리를 확인한다.
CSV 점수를 재계산할 때는 pandas read_csv의 float_precision='round_trip'을 사용한다.
임계값 바로 경계의 미세한 반올림 차이가 판정을 바꿀 수 있기 때문이다.
