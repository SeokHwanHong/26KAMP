1. 데이터 현황
======================================================================
[라벨 데이터] data/origin/moldset_labeled_cn7.csv
- 1,211행, 입력 24개 공정 변수 + PassOrFail(0 정상 / 1 불량)
- 불량 17행(1.4%). 불량 인덱스: 47, 80, 95, 99, 101, 103, 105, 107, 109, 111, 113, 115~120
- 모든 값은 컬럼별로 표준화된 값(평균 0, 표준편차 1). 실제 단위(초·bar·℃)로 복원 불가
- Clamp_Open_Position은 라벨 데이터에서 상수(전부 0)
- 변수별 고유값이 적음(예: Injection_Time 15개). 좁은 운전 조건만 담고 있음

[비라벨 데이터] data/origin/moldset_unlabeled_cn7.csv
- 35,239행. 원본 인덱스 114,610~777,220, 단조 증가
- 인덱스가 1,000 이상 벌어진 지점 44곳 → 여러 운전 기간이 섞여 있을 가능성
- 변수별 고유값이 라벨보다 훨씬 많음(예: Injection_Time 115개)

[전처리(보수적)] data/processed/cn7/conservative/
- 24개 값이 완전히 같은 행을 하나의 패턴으로 통합, 불량 이력이 하나라도 있으면 위험(1)
- 라벨: 1,211행 → 606패턴(정상 592 / 위험 14). 정상·불량이 함께 관측된 상충 패턴 11개
- 비라벨: 35,239행 → 28,771패턴

[분할] 고정 test 20% + 개발 80% 내부 Stratified 4-fold (seed 42)
- 개발 484패턴(위험 11), test 122패턴(위험 3)

======================================================================

- 개발 OOF: F1 0.50 (TP 4, FP 1, FN 7)
- 고정 test: F1 0.00 (TP 0, FP 0, FN 3) → test 불량 3건을 모두 놓침
- 이전 FPR 제약 방식(1%/3%/5%)에서도 test TP는 모두 0

5. 선택 6개 컬럼 시각화 (인덱스 0:375)
======================================================================
대상: Plasticizing_Position, Max_Injection_Speed, Max_Back_Pressure,
      Average_Back_Pressure, Mold_Temperature_3, Mold_Temperature_4
- 불량 17건 모두 이 구간에 있고, 대부분 95~120에 몰려 있음
- 116~120: Max_Injection_Speed가 약 9.5로 급등(평소 -1 근처),
  같은 시점 배압 두 컬럼이 -2.8까지 급락
- 95~113: 튀는 값 없이 정상과 비슷한 수준. 배압이 완만히 내려가는 흐름만 보임
- Plasticizing_Position 고유값 4개, 금형온도 6~7개 → 연속값보다 단계형 설정값에 가까움

[컬럼 간 순위상관(Spearman)]
- Max_Back_Pressure ↔ Average_Back_Pressure: 0.95 (사실상 같은 신호)
- 배압 ↔ Max_Injection_Speed: 약 -0.67 (반대로 움직임)
- Mold_Temperature_3 ↔ Mold_Temperature_4: 0.60
- Plasticizing_Position: 다른 컬럼과 거의 무관(|r|<0.1)
→ 6개 컬럼은 사실상 3개 신호(배압·사출속도 / 금형온도 / 가소화 위치)

[종합 지표]
- PCA: PC1(42%) = 배압↑ + 사출속도↓, PC2(27%) = 금형온도 평균
- 마할라노비스 거리(정상 99% 분위 기준선 3.78):
  기준선 초과 불량 6/17(116~120 구간), 기준선 초과 정상 4/358
- 116~120만 명확히 분리되고 나머지 불량은 정상 군집 안에 섞임

6. 24개 컬럼 전체 근거 확인
======================================================================
노트북: EDA/cn7_defect_factor_analysis.ipynb

[116~120 급변 이벤트] 전체 정상 대비 |z| 평균 상위
- Max_Injection_Speed 12.6 / Filling_Time 4.4 / Injection_Time 4.3 /
  Max_Injection_Pressure 3.7 / Cushion_Position 2.7 / 배압 2.4~2.5
- 5행이지만 고유 입력 패턴은 3개 → 사실상 한 번의 사건
→ 배압보다 사출속도·충전시간·사출압력 등 "사출 쪽" 변화가 중심

[나머지 불량 11건 vs 전체 정상]
- 모든 컬럼이 정상 범위 안에서 1~1.5σ 수준 차이
- p<0.01 컬럼 11개: 금형온도 3·4, Plasticizing_Position, 충전·사출시간,
  사출속도, Clamp_Close_Time, 가소화 시간, 배압 2개, Cycle_Time

[같은 시기(인덱스 80~130) 정상 35행과 비교]
- 위 11개 컬럼의 차이가 모두 사라짐(p≥0.05)
- 약하게 남은 것은 Hopper_Temperature 하나(p=0.023)
→ 전체 정상 대비 차이는 불량 때문이 아니라 "그 시기의 운전 조건" 때문

7. 핵심 인사이트
======================================================================
1) 배압을 주요 불량 요인으로 볼 근거는 없다.
   배압은 116~120 이벤트에서 함께 움직인 변수 중 하나이며, 시기 효과를 제거하면
   나머지 불량에서도 차이가 사라진다.

2) 데이터로 확실히 확인되는 불량 신호는 "사출속도 급변 이벤트" 한 건뿐이다.
   사출속도 급등 → 충전·사출시간 단축 → 사출압력·쿠션·배압 변화가 동시에 나타남.
   단, 고유 패턴 3개짜리 단일 사건이라 일반화는 어렵다.

3) 나머지 불량(95~113 등)은 현재 24개 입력값으로 정상과 구분되지 않는다.
   같은 입력값에서 정상·불량이 함께 관측된 상충 패턴도 11개 있어,
   어떤 모델로도 넘을 수 없는 성능 상한이 데이터에서 정해져 있다.

4) 불량이 특정 시기에 몰려 있어 "시기 효과"가 강하다.
   요인 분석·모델 평가 모두 전체 정상이 아닌 같은 시기 정상과 비교해야 착시를 피한다.

5) 라벨·비라벨의 표준화 좌표계가 달라 pseudo-labeling이 오히려 성능을 떨어뜨렸다.
   (OOF F1 0.50 → 0.18, 배치 점수 PSI 3.5~8)

6) test 불량이 3건뿐이라 1건 차이로 결론이 뒤집힌다.
   개선 여부 판정은 반복 CV 등 여러 번 재는 방식이 필요하다.
