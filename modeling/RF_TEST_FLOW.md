# PNG 7단계 기준 RF 실행·검증

이 실행기는 `seoloo`의 기존 RF 정의를 재사용한다. 팀원 TXT는 검증 방식의 참고 자료이며 그 안의 LR 구현·전체 운영 구축 명령을 이 저장소의 RF 작업 지시로 실행하지 않는다.

## 실행

프로젝트 루트에서 RF 환경의 Python을 사용한다. 실제 검증 환경은 [requirements-rf-pipeline.txt](requirements-rf-pipeline.txt)에 기록한다.

```powershell
.\.work\rf-env\Scripts\python.exe modeling\run_rf_checks.py
.\.work\rf-env\Scripts\python.exe modeling\run_rf_modeling.py
```

첫 명령은 분할 탐색 파일 검증 4개와 RF 파생변수·학습 분리·추론·기준선·감사 테스트 12개를 실행한다. 결과는 `output/rf_test_runs/<고유ID>/`에 저장한다. RF 통합 학습 명령은 CN7·RG3를 각각 캐시 없이 새로 학습한다. 결과는 `output/random_forest_pipeline/<고유ID>/{cn7,rg3}/`에 저장한다. 단일 대용량 탐색 CSV를 요구하지 않는다.

새 결과 폴더의 `.gitattributes`는 감사 파일의 정확한 바이트를 보존한다. 새 RF 결과를 공유할 때 이 파일도 함께 보존한다. 저장소 루트의 팀원 설정은 수정하지 않는다.

학습 범위는 데이터셋별 7구성×108설정×4fold, 설정당 임계값 1,001개다. 설정당 임계값을 평가할 때 모델을 다시 적합하지 않는다. 7구성은 원변수, 형체/주기 제외, 압력, 가소화, 열 상태, 도메인 전체, 공정군 PCA다. 압력·RPM·배압 상대편차와 배럴·금형 상대수준/편차는 train 정상 기준 z에서 생성한다. 활성 센서가 2개 미만인 항목은 생략하고 `feature_audit.json`에 남긴다. RF 자체는 정상·위험 train 전체를 학습한다.

|---|---|

| 4 배치 추론 | RF 전용 CSV/API 추론. 정합 확인 필요, 저장 변환 사용, 패턴과 원본 제품 예측 연결·max 라벨·빈도 보존 |

팀원 기록의 `03.modeling/tests/run_checks.py`, `pipeline_runtime.py`, LR 실행기는 현재 저장소에 없다. 그 기록의 43회 테스트가 여기서 실행됐다고 보고하지 않는다.

## 저장 결과 재감사·추론

```powershell
.\.work\rf-env\Scripts\python.exe modeling\rf_pipeline.py audit <실행폴더\cn7>
.\.work\rf-env\Scripts\python.exe modeling\rf_pipeline.py infer <실행폴더\cn7> <배치.csv> --coordinates-confirmed --label-source <검사출처>
```

꺾쇠 항목은 실제 값으로 바꾼다. 비라벨 입력은 `--label-source`를 생략한다. `--coordinates-confirmed`는 좌표/스케일 정합 확인을 의미하며 임의로 선언하면 안 된다. 입력 컬럼은 `Unnamed: 0` 원본 제품 ID, 입력 24개, 선택적 `PassOrFail`이다. 라벨이 있으면 출처와 0/1 유효성을 요구한다. 배치 결과는 실행폴더 아래 새 `batch-<ID>/`에 저장한다. 실제 현장 배치가 제공되지 않은 이번 작업의 배치 테스트는 합성 자료로 수행한다.

## 테스트·성능 해석

- 원본·고정 분할·팀원 소스·기존 RF 결과·runtime의 작업 전후 해시를 대조한다.
- 초기 모델 재학습과 신규 배치 CT는 구분한다. 개발 전체 재적합은 CT가 아니다.
- 기술 테스트의 통과는 모델 성능의 충분성을 뜻하지 않는다. OOF는 선택에 사용한 튜닝 성적, 기존 Test는 과거 관찰 후속 평가다.
- 현재 RF 점수는 위험 이력 라벨에 대한 모델 출력이며 개별 제품의 실제 불량 확률로 표현하지 않는다.
- 공정군 순열 중요도는 모델의 검증 민감도다. 물리적 불량 원인의 증명이 아니다.
- 환경이 다른 과거 결과와 비교할 때 연속 점수의 허용오차·판정 일치·임계값까지 거리를 함께 확인한다. 단순 비트 일치 실패만으로 모델 결함이라 판단하지 않는다.
