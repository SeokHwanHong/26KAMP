# 정상 관계식과 잔차 기반 품질 위험 학습

가설은 **다른 공정값으로 예상한 센서값과 실제 센서값의 차이가 불량 이력 또는 원본 불량 판정에 추가 정보를 주는가**이다. 관계가 잘 예측된다는 사실과 불량을 잘 구별한다는 사실을 분리해 검증한다.

## 실행

```powershell
python modeling/test_relationship_residual_pipeline.py
python modeling/relationship_residual_pipeline.py --run-id <새로운실험이름>
```

`relationship_residual_analysis.ipynb`에는 분석 코드 사본과 저장된 실제 결과를 읽는 셀이 있다. 기본값은 결과 열람이며 `RUN_NEW_EXPERIMENT=True`와 새로운 `RUN_ID`를 지정하면 전체 실험을 실행한다. 기존 실행 폴더가 있으면 덮어쓰지 않고 중단한다.

원본 CSV, 기존 전처리 및 분할, OCSVM 노트북은 변경하지 않는다. `kamp_data` 원본에서 집계한 패턴과 기존 패턴 파일이 일치하는지 확인한다. 결과는 `output/relationship_residual/<run-id>/`에 저장한다.

## 비교 구조

1. 각 학습 fold의 정상 전용 패턴 중 50%를 관계식 참조 자료로 분리한다.
2. 나머지 정상 및 모든 위험 자료로 분류기를 학습한다. 동일 입력 패턴이 두 역할에 걸치지 않는다. 원본 행 실험에서는 정상·불량이 공존한 학습 패턴을 정상 참조에서 제외한다.
3. 참조 정상만으로 각 현재 변수를 다른 변수에서 예측한다. 자기 자신의 현재값은 입력에서 제외한다.
4. 관계 예측기는 Ridge와 ExtraTrees다. 참조 정상 내부의 그룹 분리 3-fold OOF R²가 0.2 이상인 관계만 사용한다. 이 기준은 test에서 고르지 않는다.
5. `(실제값 - 예상값) / 정상 OOF 절대오차 Q90`을 잔차로 만든다. 0에 가까운 분모를 막기 위해 정상 표준편차의 5% 및 1e-8을 최솟값으로 사용한다. 이 값은 확률·신뢰구간이 아니다.
6. 동일 설정의 LR/RF로 원변수, 잔차, 원변수+잔차를 비교한다. 절대 잔차 상위 3개 평균을 사용하는 비지도 기준선도 포함한다.
7. 합산 validation F1로 임계값과 대표 후보를 선택해 manifest를 고정한 다음 test를 평가한다.

### 비교 모델

- `raw_full_*`: 정상 참조 분리 없이 원래 학습 자료 전체로 학습하는 강한 기준선.
- `raw_matched_*`: 잔차 분류기와 같은 행으로 학습하는 비교군. 입력 표현의 효과를 비교한다.
- `ridge_residual_lr`, `extra_residual_lr`: 잔차만 사용.
- `*_augmented_*`: 원변수와 잔차를 함께 사용.
- `*_unsupervised_top3`: 표준화된 절대 잔차 상위 3개 평균.

관계식은 정상 참조, 분류기는 나머지 자료에 적합하므로 관계식이 외운 정상 자료의 작은 잔차를 분류기가 그대로 학습하는 문제를 피한다. 그 대가로 지도학습에 쓰는 정상 수가 줄어든다. 두 종류의 원변수 기준선을 모두 보고한다.

## 평가 프로토콜

### 고정 패턴

- 기존 4-fold 및 test 배정을 유지한다.
- 목표는 불량 이력이 한 번이라도 있는 입력 패턴이다.
- 최종 개발 자료로 재학습한 후 validation 임계값을 그대로 적용한다. 재학습에 따른 점수 이동 가능성을 test에서 확인한다.
- 같은 입력의 상반된 원본 라벨을 따로 구별하는 실험이 아니다.

### 시간순 가정

- 원본 파일 순서를 생산 순서로 **가정**한다. 실제 시간순임을 증명하지 않는다.
- 원래 행 라벨을 사용한다. 현재값, 직전값, 이전 3행 평균·표준편차를 입력으로 사용한다.
- 약 60/20/20 구간을 나누고 반복 패턴 경계를 보정하며 검증/test 앞에 3행의 간격을 둔다.
- train-only 모델과 validation 임계값을 유지해 이후 구간을 평가한다. test 직전까지의 실제 입력값은 관측 가능한 과거 문맥으로 사용한다.
- 정상 참조 내부 관계 품질 평가는 외부 train 안에서 GroupKFold를 사용한다. 이 내부 점수는 미래 생산 성능의 추정이 아니다.
- CN7은 미래 validation에 불량이 없어 탐지 검증을 건너뛴다. 임의로 불량을 뒤로 옮기지 않는다.
- 패턴 목표와 행 목표의 성능을 같은 분모로 비교하지 않는다.

## 결과 파일

| 파일 | 내용 |
|---|---|
| `config.json` | 설정·환경·소스 및 코드 해시 |
| `role_plan.json`, `final_fit_roles.json` | 참조·분류기·검증·test 행 |
| `relationship_oof_quality.csv` | fold별 정상 관계 예측 품질과 채택 여부 |
| `linear_relationship_equations.json` | 실행 가능한 표준화 선형 관계식 계수 |
| `validation_comparison.csv` | 후보 선택 근거 |
| `selection_manifest.json` | test 전 고정한 모델과 임계값 |
| `test_comparison.csv` | 모든 후보의 후속 평가. test 최고 후보로 재선택하지 않음 |
| `test_topk_tie_aware.csv` | 동점 무작위 처리를 가정한 상위 검사량별 탐지 기대값과 범위 |
| `test_normal_relationship_quality.csv` | 후속 test 정상에서 관계 자체가 유지되는지 확인 |
| `test_residual_explanations.csv` | 행별 큰 관계 이탈 3개. 원인 설명이 아님 |
| `experiment.joblib` | 참조 변환·관계 모델·분류기. 임계값은 selection manifest와 함께 사용 |
| `analysis_summary.txt` | 실제 결과 요약 |
| `verification.json`, `run_verification.json` | 원본 보존·선택 동결·모델 재로딩 검증 |

저장 모델은 `modeling`을 Python import 경로에 추가한 후 불러온다. 신뢰하는 로컬 joblib 파일만 로드한다. `predict(context,current)`는 입력 열 계약을 유지한 위험 점수를 반환하며, 판정은 manifest의 모델별 임계값에 대해 `score > threshold`를 사용한다.

## 해석 한계

- 기존에 관찰한 데이터와 test를 다시 사용한 후속 탐색이다. 독립 검증이나 배포 적합성을 주장하지 않는다.
- R²가 높은 정상 관계가 반드시 불량 판별에 유용하지는 않다.
- 선형 관계식의 계수는 물리 법칙이나 인과효과가 아니다. 제공값의 물리 단위 복원도 수행하지 않는다.
- 비라벨 데이터는 좌표계 정합과 정답이 확인되지 않았으므로 학습·평가에 사용하지 않는다.
- 원본 정상·불량이 같은 입력을 가지면 정적 잔차도 같다. 잔차 변환이 없는 정보를 만들어내지 않는다.
- 검증 F1로 최적화한 결과는 낙관적일 수 있다. CN7 test 위험 3개와 RG3 test 위험 5개로 현장 신뢰도를 확정하지 않는다.
- 이항 재현율 구간은 참고용이다. 관측 독립성 위반, 모델 선택, 분포 이동에 따른 불확실성을 모두 포함하지 않는다.
