## 단계의 목표

확인된 변화와 원인, 실제 라벨, 충분한 표본을 근거로 독립적인 재학습 후보를 만드는 단계다.

## 날짜별 진행

### 초기 논의 · 날짜 미확정

비라벨 예측을 pseudo-label로 재학습하는 구상을 검토했다. 현재 기본 운영 경로에서는 채택하지 않았다.

### 2026-10-03

IF·OCSVM은 정상 패턴, LR·RF는 정상·위험 패턴으로 전체 재학습하는 CT를 구현했다. 비라벨 및 평가 자료의 학습 유입을 차단했다.

### 2026-10-05

공통 운영 잠금과 전환 준비 상태에 CT를 연결했다. CN7/RG3 격리 종단 리허설에서 LR 후보 생성과 평가 보류·유지를 확인했다.

## 기능 구현과 문제 해결

### 기능 11. 조건부 지속학습 CT

**주요 날짜:** 10-03 구현, 10-05 운영 연결 검증.

**구현:** 변화 검토, 원인 기록, 실제 라벨, 정상·위험 고유 표본 조건을 만족하면 모델별 독립 후보를 생성한다. IF·OCSVM은 정상 패턴, LR·RF는 정상·위험 패턴으로 전체 재학습한다.

**보호:** 비라벨·예측 라벨·평가용 패턴을 학습에 사용하지 않고 기존 위험 이력을 새 정상 라벨로 자동 제거하지 않는다. 후보 생성과 운영 교체를 분리한다.

**회고:** 초기 pseudo-label 반복 학습 구상은 현재 기본 운영에서 채택하지 않았다. 확인되지 않은 예측을 정답으로 되먹이는 위험을 줄이고 실제 검사 근거에 기반한 재학습을 택했다. 현재 CT는 전체 재학습이며 LR `partial_fit` 운영 구현은 아니다.

## 회고

변화가 생겼다고 즉시 재학습하면 공정 이상을 새 정상으로 흡수할 수 있다. 학습 자동화보다 학습을 허용하는 조건과 실제 라벨의 출처를 설계하는 일이 중요했다.

## 남은 과제

실제 원인 확인 절차와 라벨 확보 주기를 정해야 한다. 현재 CT는 전체 재학습이며 온라인 partial_fit 구현으로 표현하지 않는다. 새 종단 리허설이 모든 모델 조합을 검증한 것은 아니다.

## 현재 검증 상태

전체 파이프라인 최종 회귀 **122개와 저장 CN7/RG3 LR 감사가 통과**했다. 122개는 이 단계만의 검사 수가 아니라 전체 회귀 합계다. 마지막 수정 전후 실제 운영 runtime과 기존 LR 파일 120개의 해시는 같았다. 기능 검증은 격리 환경에서 수행했으며 현장 예측 성능 입증으로 해석하지 않는다.
