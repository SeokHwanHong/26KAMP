Codex가 마지막 P0 재전송 결함을 직접 수정했으므로 이전 코드로 되돌리지 마.

전달 파일: KAMP_아키텍처_5.png, KAMP_변경사항중심_통계논리흐름_검토보고서_20261005_개정.pdf.
작업 목표는 7단계 흐름의 안내·모델·기준선 버전 및 상태 전환을 일관되게 연결하는 것이다.
새 모델 탐색, 현장 성능 튜닝, 입력 변수 추가, DB·웹 서비스 구축은 이번 범위에서 제외한다.

직전 Codex 수정 요약
- manifest 파일 누락/손상 + 원장 또는 processing 수집 이력이 있으면 rejected. 재수집·중복 원장 방지.
- 신규 수집의 ID 계약은 manifest에도 기록. processing 유실 시에도 원래 A/C 계약을 확인.
- 실제 이전 기록에서 계약 정보와 ID 색인 근거가 부족하면 rejected. 미등록을 C로 추정하지 않음.
- 동일 생산·같은 ID 재전송만 허용. 제품 ID·입력·라벨 연결 변경은 conflict.
- ResendMatrixTests에 실패 단계·manifest 손상·ID 색인 유실·라벨 상태 조합과 파일 불변 검증 추가.
- 이전 C 자료의 계약 근거가 없으면 자동 마이그레이션하지 말고 원천 확인이 필요하다는 한계를 유지.

작업 원칙
1. 현재 변경사항을 읽고 보존해. git reset/clean, 과거 테스트 결과 덮어쓰기 금지.
2. 실제 운영 runtime·원본 데이터·고정 분할·기존 LR 결과를 변경하지 마.
3. 모델 전환 검증은 독립 state-root의 합성 fixture에서 실행해.
4. run_checks_only.py를 검증 진입점으로 써. 실제 RF 등록 실행기를 검수 목적으로 실행하지 마.
5. 전처리의 24개 입력·정확한 패턴 통합·max(label)·제품 관측/빈도 보존을 유지해.
6. 운영 계층의 변경은 정확한 버전·상태·복구에 국한해. 추론 시 scaler 재적합 금지.
7. 단계별로 구현·테스트 결과를 제시하면 Codex가 검수하고 발견한 결함은 Codex가 직접 보완할 예정이다.

P1-1. 안내 재개 시 근거 버전 고정
- 배치 추론의 모델, 감지 기준선·정책, 안내의 참조 버전을 각각 저장해.
- advice_failed 후 모델이 교체돼도 기존 배치 resume가 현재 active 모델을 몰래 사용하지 않도록 해.
- 기본은 최초 기록의 모델·기준선 재사용. 원래 근거가 없거나 손상됐으면 명시적으로 실패해.
- 새 버전 재산출이 필요하면 별도 revision과 이유·원래 기록을 연결하고 점수·순위·근거를 함께 갱신해.
- CN7/RG3 모두 안내 실패→버전 변경→재개 시나리오로 확인해.

P1-2. waiting 배치와 후속 감지 윈도 연결
- processing completed와 분포 판단 확정 여부를 별도로 표현해.
- waiting 배치가 나중 윈도에 포함되면 batch→drift 연결 및 최신 판단 조회를 제공해.
- 과거 안내는 당시 이력으로 보존하고 최신 안내·현재 판정과 구분해.
- 안내 최신화 때문에 배치를 재수집하거나 감지 윈도를 다시 소비하지 마.
- waiting→watch/review, 업데이트 도중 실패/재개, repeated resume의 멱등성을 검증해.
- 불확실성·분포 변화·추가 검사 권고를 분리하고 normal도 제품 품질 보증으로 표현하지 마.

P1-3. 모델 전환·기준선 준비 실패 복구 및 동시 명령
- ingest/detect/promote/rollback의 동시 실행에서 잠금 획득 순서와 확정 구간을 정의해.
- 감지·추론·안내가 서로 다른 모델/기준선 조합을 무심코 사용하지 않도록 해.
- 새 기준선 준비 후 모델/기준선 전환 또는 명시적 전환 저널을 사용해 일관된 상태만 노출해.
- 기준선 준비 실패·포인터 저장 실패·롤백 실패를 각각 기록하고 같은 작업으로 재개/복원 가능하게 해.
- 모델과 기준선이 불일치할 때 추론을 막고 상태를 명시해.
- 새 배치를 자동으로 정상 참조에 편입하지 마. 입력 참조 유지와 모델 출력 기준선 갱신을 구분해.
- 서로 다른 경보 정책의 동시 detect도 캐시 서명과 실제 경보선이 일치해야 해.
- 실제 2개 프로세스 경쟁 또는 이에 준하는 실행 검증으로 잠금/복구를 확인해.
