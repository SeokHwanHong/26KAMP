# RG3 보수적 공정 관리 전처리

이 폴더는 불량 이력을 우선하는 새 패턴 단위 학습 자료입니다.
상위 rg3 폴더의 원본 행 유지 자료 및 기존 3-fold 메타데이터와 혼용하지 마세요.

- X_labeled.csv: 동일 24개 입력을 통합한 591개 패턴. 메타데이터는 입력에 포함하지 않습니다.
- y_labeled.csv: 같은 행 순서의 대표 라벨. 정상 566개, 위험 25개입니다.
- labeled_metadata.csv: pattern_row, pattern_id, 정상/불량/전체 관측 수, 상충 여부, 원본 ID 목록, 대표 행입니다.
- source_row_mapping.csv: 원본 1,182행에서 통합 패턴으로 연결합니다. source_row와 pattern_row는 0부터 시작합니다.
- X_unlabeled.csv: 비라벨 35,941행을 29,707개 고유 패턴으로 통합합니다. 입력값과 24개 컬럼 순서는 유지합니다.
- unlabeled_metadata.csv: 비라벨 패턴별 대표 행, 관측 횟수와 원본 ID 목록입니다.
- unlabeled_source_row_mapping.csv: 비라벨 원본의 모든 행을 통합 패턴에 연결합니다. pattern_row로 예측을 원본 순서에 복원할 수 있습니다.
- preprocessing_manifest.json 및 validation.json: 정책, 품질 점검, 해시, 검증 결과입니다.

통합 전 불량 25행의 이력은 모두 보존합니다. 정상과 불량이 공존하는 25개 패턴을 모두 위험으로 통합합니다.
비라벨에는 불량 우선 집계를 적용하거나 라벨을 생성하지 않습니다. 두 파일의 패턴 ID는 공통 물리 조건을 의미하지 않습니다.
제공 단계의 파일별 표준화 좌표계 정합은 아직 확인되지 않았습니다.
분할, KS 기반 특징 선택, 학습 구간 상수 제거 및 스케일링은 후속 단계입니다.
분할은 test 20% 고정 및 개발 80% 내부 4-fold로 계획되어 있습니다.
