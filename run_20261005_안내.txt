3. 결과 읽는 법 (20261005_실행로그.json)
========================================================================
run_checks.passed      true = 전체 검사 통과 / false = 실패(output 항목에 실패 내용)
run_checks.output      검사 출력 마지막 부분. 상세 로그는 output\test_runs\<실행ID>\ 폴더
                       runtime_unchanged=true 이면 검사 중 운영 폴더(runtime)가 바뀌지 않았다는 뜻
rf.status              initialized    = 이번에 RF를 새로 등록함(version, baseline 표시)
                       already_active = 이미 RF가 등록돼 있어 건너뜀
                       error          = 등록 중 오류(traceback에 원인)
                       "건너뜀: ..."   = 전체 검사가 실패해서 등록하지 않음
