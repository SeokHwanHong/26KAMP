KAMP CN7·RG3 파이프라인 — 통계/ML 외 추가 모델링 아이디어
(위상수학적 접근 + 인문학적 접근)
작성일: 2026-10-01


[ 위상수학적(TDA) 접근 ]

1. 지속적 호몰로지(Persistent Homology)로 레짐 경계 탐지
   현재 파이프라인 4단계 "레짐 전환 점검"은 이동평균으로 보고 있음.
   이를 더 수학적으로 보강하는 방법:
   - 연속된 사이클 묶음(슬라이딩 윈도우)을 점구름(point cloud)으로 보고
     persistence diagram을 계산
   - 윈도우끼리 비교(Wasserstein distance / Bottleneck distance)해서
     거리가 급격히 튀는 지점을 "레짐 전환점"으로 판정
   - "평균이 바뀌었다"가 아니라 "데이터의 위상적 구조(모양) 자체가
     바뀌었다"는 더 강한 수학적 근거가 됨

2. Mapper 알고리즘으로 공정 전체의 "지형도" 그리기
   - PCA 산점도 대신(또는 같이) Mapper로 전체 사이클을 노드-엣지
     그래프로 압축
   - 레짐들이 서로 다른 "가지(branch)"로 갈라지는 구조, 불량이 특정
     가지에 몰려있는지 가지 사이 "다리(bridge)"에 몰려있는지를 시각화
   - 발표평가에서 "2차원으로 단순히 눌러본 게 아니라 데이터의 실제
     위상 구조를 봤다"는 설득력 있는 그림이 됨

3. 위상적 특징을 파생변수로 — Betti number
   - 연결된 덩어리 개수(β0), 고리/순환 구조 개수(β1) 등을 윈도우별로
     추출해 LR/RF/SVM 입력 피처로 추가
   - "통계적 파생변수" vs "위상적 파생변수"의 예측력을 비교하면 그
     자체로 공고문이 요구하는 Ablation Test 결과가 됨

4. Takens 임베딩으로 단일 센서의 "운동 궤적" 복원
   - 예: Max_Injection_Speed 시계열을 시간지연 임베딩해 고차원
     궤적(attractor)으로 복원
   - 정상 구간과 이상 구간의 궤적 모양(위상)이 다른지 비교
   - 비선형동역학 기법 — "몇 가지 설정값 조합으로 운전되는" 사출성형
     공정 특성과 잘 맞을 수 있음

실무 참고:
   - 파이썬 라이브러리: giotto-tda, ripser, kepler-mapper
     (Jupyter/Anaconda 환경에서 바로 구동 가능)
   - 비라벨 데이터 3만 건 이상에 통째로 적용하면 계산량이 크므로,
     윈도우 단위로 쪼개거나 서브샘플링해서 적용 범위를 좁히는 것이
     현실적


[ 인문학적 접근 ]

1. 암묵지(Tacit Knowledge) 포착 — 숙련공 인터뷰를 모델에 녹이기
   - 현재 파이프라인은 전부 데이터 기반. 베테랑 작업자의 경험적
     판단("이 소리 나면 불량 난다" 등, Polanyi의 암묵지 개념)을
     인터뷰로 수집
   - 이를 사전 지식(prior)이나 파생변수 설계 근거로 활용
   - Enterprise Knowledge Loop(VOC·부서 의견을 검증된 지식으로
     자산화)와 접근 방식이 유사 — 지식 검증·자산화 프레임을 KAMP
     문제정의 단계에 적용 가능

2. 서사(Narrative) 구조로 이상탐지 설명하기
   - SHAP 수치를 단순 나열하지 않고 "정상(발단) → 이상 징후
     누적(전개) → 임계점 돌파(위기) → 불량(결말)"이라는 이야기
     구조로 번역
   - 기술적으로는 "이상 점수가 시간에 따라 누적되는 궤적"을 하나의
     지표(서사형 건강도 지수)로 구성
   - 발표자료에서 숫자 나열보다 훨씬 설득력 있게 전달됨

3. 의사결정 윤리 프레임 — 비용 기반 임계값의 철학적 정당화
   - "왜 Recall을 우선했는가"를 손해비용 계산으로만 끝내지 않고,
     공리주의(전체 손실 최소화) vs 의무론(불량을 놓치는 행위 자체의
     책임) 같은 윤리학 프레임으로 짧게 논증
   - 서면평가 심사위원(제조 현장 관계자 포함)에게 "AI를 현장에
     책임감 있게 적용하는 법까지 고민했다"는 인상을 줄 수 있음

4. 혼합방법론(Mixed-Methods) — 레짐 전환의 "원인"을 질적으로 검증
   - 기존 EDA에서 레짐 전환의 원인(설비 변경? 교대조 변경? 금형
     교체?)은 데이터만으로 알 수 없다는 한계가 있었음
   - 현장 인터뷰나 작업일지 열람(참여관찰·에스노그라피 방법론)으로
     보완
   - 정량분석(위상수학/통계) + 정성조사를 결합한 혼합방법론 리포트 —
     준비가이드가 강조하는 "현장 적용 가능성" 점수와 직결, 통계
     전공자들이 잘 쓰지 않는 접근이라 차별화 확실


[ 기존 파이프라인에 붙이는 방법 ]

- 2단계(EDA·전처리): persistence 기반 레짐탐지를 기존 통계적 방법과
  나란히 추가
- 3단계(최초학습): 위상적 파생변수(Betti number 등)를 LR/RF/SVM
  입력에 추가해 비교
- 보고서 "현장 적용 방안·기대효과" 섹션: 암묵지 인터뷰 결과와 서사형
  설명을 반영

기존 7단계 구조를 크게 바꾸지 않고도 엔터프라이즈급 차별화 포인트를
더할 수 있는 방향들임.
